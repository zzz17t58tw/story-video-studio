====================================================
 Story Video Studio（乾淨版）使用說明
 發佈日期：2026-11-18（含「一鍵佈署」新功能）
====================================================


【一、怎麼開程式】

1. 把整個 StoryVideoStudio 資料夾解壓到你要放的地方
   （例如 D:\StoryVideoStudio ，路徑建議用英文、不要放進
    OneDrive／Dropbox 這類會自動同步的資料夾）。
2. 雙擊資料夾裡的 StoryVideoStudio.exe 就會打開程式。

   不需要打任何指令，不需要另外開瀏覽器，也不會跳出黑色命令視窗。
   第一次打開會慢幾秒是正常的（程式在解壓內建資源）。

注意：StoryVideoStudio.exe 和 _internal 資料夾是一組的，
不要把 exe 單獨複製到別的地方，否則打不開。


【二、你的資料在哪裡 / 怎麼備份】

所有資料（專案、人物、場景、鏡頭、圖片、影片）都放在
exe 旁邊的 projects 資料夾裡。

備份方法：把整個 projects 資料夾複製走就好 (複製到外接硬碟、
雲端或另一台電腦)。要還原就是把資料夾放回 exe 旁邊。

這個乾淨版裡面已經有一個完整成果專案：

    雨夜便利商店（project-20261118-022129）
    3 個人物 / 2 個場景 / 6 個鏡頭
    成片：output\final_20261118-033215.mp4（約 31 秒，含聲音）

打開程式後在左側專案列表選它，點右上角的播放鈕就能看成品。


【三、要生成圖片或影片時】

程式本身不負責算圖，會呼叫你自己電腦上的 ComfyUI：

1. 先把 ComfyUI 開起來，確認它跑在
       http://127.0.0.1:8000
2. 再開 Story Video Studio。

程式右下角會顯示 ComfyUI 的連線狀態。
顯示「未連線」時，生圖／生影片會被擋下來並提示你先開 ComfyUI，
其他功能（編輯文字、看成品、合併已生成的影片）不受影響。

模型需求：生圖預設用 MOSS Image SFT，生影片用 H3 導演台。
模型檔不在這個壓縮檔裡，要沿用你原本 ComfyUI 的模型。


【四、跟模型對話（修改故事 / 人物 / 鏡頭文字）】

設定頁可以選兩種對話來源：

  本機   ：http://127.0.0.1:8080 （你自己的 llama.cpp / 本機模型服務）
  線上   ：DeepSeek 線上模型（需要 API key，在設定頁填一次就會記住）

本機模型回應可能要幾分鐘（尤其長輸出），等待時請不要關視窗；
線上模型快很多，但需要網路與有效的 key。

原則：模型只會「建議文字」，一定要你自己按「套用」才會寫進專案，
不會偷偷改掉你已經寫好的內容。


【五、一鍵佈署（故事 → 角色／場景／劇本／分鏡 一次建好）】

故事寫好後，按故事頁的「🚀 一鍵佈署到各頁面」按鈕即可。
它會照你填的數字，一次把後面幾個頁面的骨架建出來：

  需要填的欄位：
    角色數      這次故事有幾個主要人物
    場景數      有幾個主要場景
    **總鏡數**  整支影片總共要幾個鏡頭（會自動分配到各場景）
    每鏡秒數    每個鏡頭幾秒（用來估總長度）

  會自動建出：角色卡、場景卡、劇本、分鏡
  圖片欄位留空 —— 只建文字與結構，不會自動生圖，
  你可以逐張確認後再手動生，避免一次燒掉大量 GPU 時間。

使用建議：

  1. 對話來源建議切「線上模型」
     （設定 → 模型服務 → 線上）。
     本機模型也能用，但長輸出較慢、有時需重試。

  2. 已有內容時的「覆盖現有內容」勾選：
     如果專案裡已經有角色／場景／分鏡，預設會勾選「覆盖現有內容」。
     勾選 = 先清掉舊的再建（推薦，結果乾淨）。
     不勾 = 接續新增在原內容後面，可能出現主題重複的角色或場景。

  3. 佈署是背景工作，跑到一半可以離開頁面，
     回來會自動接回進度；執行中不要關程式。


【六、關掉程式】

直接關視窗就好。程式會把背後的伺服器一起關掉，
不會留背景進程，也不會佔用連接埠。

如果哪天程式卡住關不掉，用工作管理員結束 StoryVideoStudio.exe 即可。


【七、已知限制】

1. MOSS 生圖沒有「參考圖鎖臉」功能，角色一致性是靠文字錨點
   （外型、髮型、服裝逐字描述）＋固定 seed 維持。
   要更穩，先用 MOSS 生一張正面全身角色立繪存成參考圖，
   再拿那張去生鏡頭圖。
2. H3 影片很吃顯示卡：每 5 秒影片大約需要 5～6 分鐘 GPU 時間
   （RTX 5070 Ti 實測）。六個鏡頭大約 30～40 分鐘，請用批次功能
   讓它背景跑，不要一次只送一鏡然後盯著等。
3. 16GB 顯示卡上「本機模型」和「ComfyUI」搶同一塊 VRAM：
   要生圖生影前先停掉本機模型，生完再開回來，設定頁的
   「GPU 資源」卡有按鈕。
4. 成品影片是 9:16 直式（專案設定的比例），播放器上會自動加黑邊。
5. 本程式只綁 127.0.0.1，不開放區網給其他裝置連線。
6. 一鍵佈署只建文字骨架、不建圖；圖與影片仍要各自按生成。


【八、資料夾裡有什麼】

StoryVideoStudio.exe   主程式（雙擊這個）
_internal\             程式執行檔與網頁介面（不要動）
projects\              你的所有專案與媒體檔（要備份就是備份這個）
使用說明.txt            本文件

其他細節：程式介面內各分頁的右上角有提示文字，
技術文件（PLAN.md、README.md）只隨開發版附帶，不在此發佈包內。
