## 這一版在修什麼

「與模型對話」的回填以前只是「幫你打字」：一次只能填一個欄位、而且章回／場次台詞／服裝這些結構化資料根本沒有可填的格子，你只能自己複製貼上——等於形同虛設。

v0.9.5 把它改成「模型回什麼，就一鍵填回對應的格子」。

## 你要做的三件事，現在的樣子

- **② 依大綱寫成章回** → 回覆下方出現「⇣ 回填到 整份章回」，把「第 N 回」自動拆成章回條目，預覽確認後寫入。
- **③ 調整風格** → 一次填滿「類型／基調／視覺風格／負向提示」四格，不用複製四次。
- **其他 23 個任務全部排查過** → 每個任務按鈕直接標「→ 回填：XXX」，你選之前就知道會填哪裡：人物外型（含英文 prompt）一次五格、服裝整份、身世四欄、音色三選一、場次 beats（角色名自動對到人物）、三版台詞「用第 N 版」直接寫入；「檢查與人物卡是否矛盾」這種只給建議的，明白標「僅建議，不回填」。

## 安全網

- 一次套用多個欄位是**整批原子寫入**：任何一項格式不合法就整批不寫，並告訴你是第幾項、哪個欄位，絕不會只寫一半。
- 只選取回覆裡的某一段（例如只有第 2 回）時，預設是「追加」而不是整份蓋掉。
- 場次台詞整份重寫時，舊句會收進「已作廢」（可還原），不會重複出現在劇本頁，也不會被送進模型。

## 安裝

下載 `StoryVideoStudio-v0.9.5-clean.zip`，解壓後執行 `StoryVideoStudio.exe`。既有專案資料夾（`projects/`）原封不動，直接沿用。
