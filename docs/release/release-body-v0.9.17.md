## 這一版是什麼

GitHub 上的 Releases 停在 **v0.9.7**，中間十個版本（v0.9.8 → v0.9.17）都在本機發佈、沒有上網。這一個 Release 一次補齊，**下載這個 zip 就是最新狀態**（v0.9.17）。

## 最重要的三件事

### 1. 影片終於長得跟你的鏡頭設定一樣（v0.9.8）

以前 9.42 秒的鏡只生出 5.17 秒（送件參數寫死 124 幀），台詞一定唸不完。現在影格數跟隨 `durationSec`（吸附 H3 合法格 17k+5），影格欄旁直接顯示「= 幾秒；本鏡設定 N 秒」。

同時修掉「系統說會用首幀鎖主體、提示詞卻沒有任何 `<Picture N>`」的斷點——首幀當 `<Picture 1>` 時會真的寫進六段式第一段。生影片的警告也從「6 條互相矛盾」改成「✓ 已自動改寫提示詞」＋最多兩條真的要你動手的建議。

### 2. 分鏡缺口現在看得見（v0.9.17）

「影片看不出在演什麼」的結構性原因：一鍵佈署的分鏡**只挑台詞、動作 beat 從來沒有鏡頭**，而驗證完全不報。

- 分鏡表上方會出現琥珀色缺口框：「⚠ 劇本有 10 個演出點沒有對應鏡頭」，逐場次列出 b01、b03… 是哪些。
- 台詞長到一鏡唸不完時，「🎬 由劇本自動分鏡」會**先依標點把那句拆段（台詞一字不改）再重建**；長度處方也從「請加長或拆鏡」變成「請把 durationSec 設到至少 13.33 秒（328 幀）或拆成 N 鏡」。
- 實測「喪屍爆發」：重建後 validate **2 error → 0 error、6 鏡 → 16 鏡**。

### 3. 一鍵佈署可以只跑你要的那一層（v0.9.16）

拆成三個範圍：角色＋場景／劇本／分鏡，各自一顆按鈕。故事頁那顆不再順手把劇本和分鏡也跑掉。

## 安裝

下載 `StoryVideoStudio-v0.9.17-clean.zip`，解壓後執行 `StoryVideoStudio.exe`。既有 `projects/` 資料夾原封不動，直接沿用。

> 本程式不含任何模型權重：生圖需要本機 ComfyUI（Qwen Image 2.1／MOSS）與對應工作流，生影片需要 MiniMax H3 導演台節點。純測試用途，生成內容的責任自負。
