## 這一版加了什麼

**給外部 AI 接手用的完整介面。** 這支程式有 59 支 API、三層資料模型（劇本 beats → 分鏡 shots → 生成）、還有一堆踩到就會白花時間的硬限制（H3 影格網格、取景規則、單張 GPU）。以前外部 AI 只能靠猜；現在它接上就能全部拿到。

## 外部 AI 會用到的三個入口

| 入口 | 內容 |
|---|---|
| `GET /api/agent/guide` | 一份約 1.7 萬字元的操作手冊（Markdown）：資料模型、硬限制、驗證規則、六個常見配方、禁止事項、全部 API 索引 |
| `GET /api/agent/manifest` | 機器可讀 JSON：每支端點的用途／何時用／副作用／參數 schema，外加 8 條硬限制、8 條禁止事項 |
| `GET /openapi.json` | 原生完整欄位型別 |

檔案版：`docs/AGENT-GUIDE.md`、`docs/agent-manifest.json`；入口檔：`AGENTS.md`。

## 為什麼不會「文件跟程式打架」

- 參數 schema **直接從程式自己的 OpenAPI 生成**，不是手抄，改了程式文件自動跟上。
- `tools/check_agent_doc.py` 會比對「所有 API」與「有寫說明的 API」，少一支就直接失敗。目前 **59/59**。

## 也含上一版的分鏡層（0.9.6）

- 劇本每個 beat（誰、說什麼、做什麼）→ 對應一顆鏡頭，一鏡只演一件事。
- 長度自動吸附 H3 合法格（5.17–15.08 秒），短句用留白補、長句自動拆鏡。
- 分鏡表由上往下讀就是整齣戲：鏡號｜職責｜誰｜台詞逐字｜秒數｜累計時間。
- 驗證 V1–V5（順序覆蓋、台詞覆蓋、長度合法、台詞唸得完、職責一致），寫入時就擋。

## 安裝

下載 `StoryVideoStudio-v0.9.7-clean.zip`，解壓後執行 `StoryVideoStudio.exe`。既有 `projects/` 資料夾原封不動，直接沿用。
